# Hide and Seek

Hide and seek is the default and original game mode of the plugin. Hiders have some amount of time to hide, then seekers must spend the remaning game time to go find them. Any hiders found will become seekers and are tasked to find the remaning hiders.

**All hiders found**

When this is set as the scoring mode, the game will not end until the timer runs out, or every last hider has been found by the seekers. Either the remaning hiders get a win, or the initial seekers.

**Last hider wins**

When this is set as the scoring mode, the game will not end until the timer runs out, or there is a single hider left. On game end, the initial seekers and last hider are the winners.
