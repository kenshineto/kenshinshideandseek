# Tag

Tag is the newest game mode added to KHS version `v2.3.0`. Instead of hiders becoming seekers joining the team to find other hiders, instead players swap teams. When a seeker "finds" a hider, the hider swaps to a seeker andis respawned while the seeker swaps to being a hider.

**Winning**

A player wins at the tag gamemode when they are still a hider once the game timer ends. Only players who joined at the start of the game will be considered.
